# Notes for coding agents

## Language

Talk to the maintainer in Italian: every message they read (answers, summaries, questions,
end-of-turn recaps). Write everything else in English: code, comments, names, commit messages,
pull requests, documentation, data files, letters to third parties and messages to other agents
or sessions. The product's own Italian texts stay Italian: `src/i18n/it.ts` is the source
language of the site and defines the shape of every other dictionary.

## Data

Upari is a free project. Use only data whose licence allows reuse with credit (CC BY, CC BY-SA,
CC BY-NC, public domain, open government data), credit every source on the page and in
`THIRD_PARTY_NOTICES.md`, and never use paid data. Accounts, API keys and written permissions
belong to the maintainer: do not register anywhere on their behalf.
